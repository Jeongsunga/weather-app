### 유저 스토리
1. 유저는 현재 위치의 날씨를 볼 수 있다. (지역, 온도, 날씨 상태)
2. 유저는 다른 도시의 날씨를 볼 수 있다.
3. 유저는 다른 도시 버튼을 클릭하면 해당 도시의 날씨 정보를 볼 수 있다.
4. 유저는 데이터가 로딩될 때 로딩 스피너를 볼 수 있다.
5. 온도에 따른 아이콘으로 직관적인 날씨를 알 수 있다.
